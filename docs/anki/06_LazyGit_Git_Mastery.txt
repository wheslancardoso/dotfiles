O que é o <b>LazyGit</b> e quais são as 3 formas mais rápidas de abri-lo no seu setup?	É uma interface visual em modo texto para Git que permite fazer commits, branches, merges e rebase com 1 único toque de tecla.<br><br><b>Como abrir:</b><br>1. No terminal comum: digite <code>lazygit</code> (ou <code>lg</code>).<br>2. Dentro do <b>LazyVim</b>: aperte <code>&lt;Espaço&gt; gg</code>.<br>3. Dentro do <b>Yazi</b>: aperte <code>M</code> + <code>g</code> (Shift+M seguido de g).	lazygit::fundamentos
Quais são os <b>4 painéis principais</b> da tela do LazyGit e como navegar entre eles?	Você pode teclar diretamente o número do painel ou usar <code>h / l</code>:<br>• <code>1</code>: <b>Arquivos / Status</b> (Arquivos modificados e stage)<br>• <code>2</code>: <b>Branches</b> (Locais e remotas)<br>• <code>3</code>: <b>Commits</b> (Histórico do branch atual)<br>• <code>4</code>: <b>Stash</b> (Alterações salvas temporariamente)<br><br><i>O painel grande à direita sempre exibe o <b>Diff de código</b> em tempo real.</i>	lazygit::navegacao
No LazyGit, como fazer <b>Stage (git add)</b> de um arquivo e como fazer de <b>todos os arquivos</b>?	No painel de Arquivos (painel 1):<br>• <code>Barra de Espaço</code>: Adiciona ou remove o arquivo selecionado do Stage (verde = staged).<br>• <code>a</code>: Adiciona <b>TODOS</b> os arquivos modificados ao Stage de uma vez.	lazygit::staging
Como fazer <b>Stage linha por linha</b> ou por bloco de código (Hunk Staging) no LazyGit?	1. Selecione o arquivo no painel 1 e aperte <code>Enter</code> (o foco vai para o Diff da direita).<br>2. Mova com <code>j / k</code> até a linha que deseja incluir.<br>3. Aperte <code>Barra de Espaço</code> na linha ou bloco desejado.<br><br><i>Para voltar para a lista de arquivos: aperte <code>&lt;Esc&gt;</code>.</i>	lazygit::staging
Como criar um <b>Commit</b> com mensagem no LazyGit?	Com os arquivos no Stage (verde):<br>1. Aperte a tecla <code>c</code>.<br>2. Uma janela flutuante abrirá: digite a mensagem do commit.<br>3. Aperte <code>Enter</code> para confirmar!	lazygit::commits
Como fazer <b>Git Push (enviar para o GitHub)</b> e <b>Git Pull (puxar atualizações)</b> no LazyGit?	• <b>Push (Subir para o GitHub):</b> aperte <code>P</code> (maiúsculo - <code>Shift + p</code>).<br>• <b>Pull (Puxar alterações):</b> aperte <code>p</code> (minúsculo).	lazygit::remoto
Como criar uma <b>nova Branch</b> ou <b>trocar de Branch (Checkout)</b> no LazyGit?	1. Pressione <code>2</code> para ir ao painel de Branches.<br>2. Para trocar de branch: navegue com <code>j / k</code> e aperte <code>Barra de Espaço</code>.<br>3. Para criar uma nova branch: aperte <code>n</code> (digite o nome e aperte Enter).<br>4. Para apagar uma branch: selecione-a e aperte <code>d</code>.	lazygit::branches
Como <b>descartar alterações indesejadas</b> de um arquivo no LazyGit?	No painel 1 (Arquivos), selecione o arquivo que você quer resetar e aperte <code>d</code>.<br><br>O LazyGit pedirá confirmação antes de apagar as alterações não commitadas.	lazygit::operacoes
Como usar o <b>Git Stash (guardar alterações temporariamente)</b> no LazyGit?	• Para guardar suas alterações atuais no Stash: aperte <code>z</code>.<br>• Para recuperar as alterações salvas: vá ao painel de Stash (<code>4</code>), selecione o stash e aperte <code>Barra de Espaço</code> (Pop Stash).	lazygit::stash
Como fazer <b>Squash ou editar um commit antigo</b> via Rebase Interativo no LazyGit?	Vá ao painel de Commits (<code>3</code>):<br>• <code>s</code> sobre um commit: Junta-o com o commit anterior (Squash).<br>• <code>e</code>: Marca o commit para edição.<br>• <code>d</code>: Deleta/descarta o commit da árvore.	lazygit::commits
Como <b>sair</b> do LazyGit e voltar para o terminal ou para o código?	Aperte a tecla <code>q</code>.	lazygit::fundamentos

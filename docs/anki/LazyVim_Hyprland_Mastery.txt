No <b>LazyVim</b>, qual é a <b>Tecla Leader</b> padrão e o que ela faz?	Pressionar <code>&lt;Space&gt;</code> (a <b>Barra de Espaço</b>).<br><br>Ela abre o menu visual <b>Which-Key</b> no rodapé mostrando todas as categorias e comandos disponíveis na hora.	lazyvim::basico
Como você busca e abre <b>arquivos por nome</b> instantaneamente no LazyVim?	Pressione <code>&lt;Space&gt; &lt;Space&gt;</code> (ou <code>&lt;leader&gt; ff</code>).<br><br>Abre a busca difusa (Fuzzy Finder / Snacks Picker) para digitar qualquer parte do nome do arquivo.	lazyvim::navegacao
Como buscar um <b>texto/código dentro de todos os arquivos</b> do projeto no LazyVim?	Pressione <code>&lt;Space&gt; /</code> (ou <code>&lt;leader&gt; sg</code> para Live Grep).<br><br>Permite encontrar qualquer função, string ou variável em todo o repositório em tempo real.	lazyvim::navegacao
Como <b>salvar</b> as alterações de um arquivo no LazyVim?	No Modo Normal:<br>• <code>&lt;Space&gt; w</code><br>• ou digite <code>:w</code> e aperte Enter.	lazyvim::basico
Como <b>sair</b> de um arquivo ou fechar o LazyVim?	No Modo Normal:<br>• <code>&lt;Space&gt; q</code> (fecha o arquivo/buffer atual)<br>• <code>&lt;Space&gt; qq</code> (encerra o Neovim)<br>• ou digite <code>:qa</code> (sair de tudo).	lazyvim::basico
Como você entra no <b>Modo de Edição / Digitação (Insert Mode)</b> e como volta ao <b>Modo Normal</b>?	• Entrar no modo de edição: pressione <code>i</code> (ou <code>a</code> para inserir após o cursor).<br>• Voltar ao modo normal: pressione <code>&lt;Esc&gt;</code>.	lazyvim::basico
Como <b>desfazer (Undo)</b> e <b>refazer (Redo)</b> uma ação no LazyVim?	No Modo Normal:<br>• <code>u</code> para Desfazer (Undo).<br>• <code>Ctrl + r</code> para Refazer (Redo).	lazyvim::basico
Como abrir e fechar a <b>árvore de arquivos lateral (Neo-tree)</b> no LazyVim?	Pressione <code>&lt;Space&gt; e</code> (ou <code>&lt;leader&gt; e</code>).	lazyvim::navegacao
No LazyVim, como pular o cursor para <b>qualquer palavra na tela</b> em 1 segundo (Flash)?	Pressione <code>s</code> e digite as <b>2 primeiras letras</b> da palavra de destino.<br><br>O plugin <b>Flash</b> destacará a palavra com uma letra guia para você teclar e saltar diretamente.	lazyvim::navegacao
Como navegar entre as <b>abas/arquivos abertos (Buffers)</b> no topo do LazyVim?	• Próximo arquivo: <code>]b</code> ou <code>Shift + l</code><br>• Arquivo anterior: <code>[b</code> ou <code>Shift + h</code><br>• Fechar arquivo atual: <code>&lt;leader&gt; bd</code>	lazyvim::navegacao
Como ir para a <b>Definição de uma função, classe ou variável (Go to Definition)</b> no LazyVim?	Coloque o cursor sobre o símbolo e pressione <code>gd</code>.<br><br>Para voltar para onde você estava, pressione <code>Ctrl + o</code>.	lazyvim::lsp_code
Como listar todas as <b>Referências e Usos</b> de uma função ou classe no projeto?	Coloque o cursor sobre o símbolo e pressione <code>gr</code>.	lazyvim::lsp_code
Como <b>renomear uma variável ou função</b> em todos os arquivos do projeto de uma vez?	Pressione <code>&lt;Space&gt; cr</code> (Code Rename).<br><br>Digite o novo nome e pressione Enter.	lazyvim::lsp_code
Como acionar as <b>Ações Rápidas de Código (Code Actions / Quick Fix)</b> no LazyVim?	Pressione <code>&lt;Space&gt; ca</code> (Code Action).<br><br>Permite aplicar sugestões do LSP, importar classes faltantes e gerar construtores/getters.	lazyvim::lsp_code
Como abrir a interface visual completa do <b>LazyGit</b> de dentro do LazyVim?	Pressione <code>&lt;Space&gt; gg</code>.<br><br>Abre o LazyGit flutuante para fazer staging, commits, branches e push com atalhos de uma tecla.	lazyvim::git
Como abrir o painel de <b>Erros e Avisos do Projeto (Trouble)</b> no LazyVim?	Pressione <code>&lt;Space&gt; xx</code>.<br><br>Lista todos os erros de compilação, sintaxe e linter do projeto com navegação rápida.	lazyvim::lsp_code
No Modo Normal do Vim, quais teclas realizam a <b>movimentação básica</b> sem tirar as mãos da linha central?	• <code>h</code>: esquerda<br>• <code>j</code>: baixo<br>• <code>k</code>: cima<br>• <code>l</code>: direita	lazyvim::basico
Como <b>deletar (recortar) uma linha inteira</b> no LazyVim e como <b>colar</b>?	• Deletar linha inteira: <code>dd</code><br>• Colar na linha abaixo: <code>p</code>	lazyvim::basico
Como <b>copiar (Yank) uma linha inteira</b> no LazyVim?	Pressione <code>yy</code> no Modo Normal.	lazyvim::basico

No gerenciador <b>Yazi</b>, como entrar em uma pasta e como voltar para a pasta pai?	• Entrar na pasta: <code>l</code> ou <code>Enter</code><br>• Voltar para a pasta pai: <code>h</code>	yazi::filemanager
No gerenciador <b>Yazi</b>, como criar um novo arquivo ou pasta?	Pressione <code>a</code> e digite o nome.<br><br>Se terminar com <code>/</code>, cria uma pasta; caso contrário, cria um arquivo.	yazi::filemanager
No gerenciador <b>Yazi</b>, como <b>deletar</b> um item selecionado?	Pressione <code>d</code>.<br><br>(Move para a lixeira com segurança).	yazi::filemanager
No gerenciador <b>Yazi</b>, como <b>copiar</b> e <b>recortar</b> arquivos?	• Copiar: <code>y</code><br>• Recortar: <code>x</code><br>• Colar: <code>p</code>	yazi::filemanager

Se o som ou microfone parar de funcionar ou der estalo, qual comando <b>recupera todo o áudio</b> em 1 segundo?	Digite <code>fix-audio</code> no terminal.<br><br>(Reinicia PipeWire, WirePlumber e reativa os presets do EasyEffects).	audio::easyeffects

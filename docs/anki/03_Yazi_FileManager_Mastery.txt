#deck:Cockpit Dev::03 - Yazi File Manager
O que é o <b>Yazi</b> e quais são os atalhos no Hyprland para abri-lo?	É um gerenciador de arquivos para terminal escrito em Rust, com suporte a pré-visualização instantânea de imagens, vídeos, PDFs e código.<br><br>• <code>Super + E</code>: Abre o Yazi ocupando o terminal no workspace atual.<br>• <code>Super + Shift + E</code>: Abre o Yazi em uma janela flutuante centralizada.	yazi::fundamentos
Como você <b>navega entre pastas e arquivos</b> no Yazi usando as teclas clássicas do Vim?	• <code>j</code>: Desce para o próximo item.<br>• <code>k</code>: Sobe para o item anterior.<br>• <code>l</code> ou <code>Enter</code>: <b>Entra na pasta</b> selecionada (ou abre o arquivo no app padrão).<br>• <code>h</code>: <b>Volta para a pasta pai</b> anterior.	yazi::navegacao
Como <b>filtrar arquivos em tempo real</b> na pasta atual no Yazi?	Aperte a letra <code>f</code> (de <i>Filter</i>).<br><br>Conforme você digita, o Yazi oculta tudo e mostra apenas os arquivos que coincidem com o que você digitou!<br><br>• Para limpar o filtro e voltar a ver tudo: aperte <code>&lt;Esc&gt;</code>.	yazi::navegacao
Como usar a busca inteligente do <b>Zoxide dentro do Yazi</b>?	Aperte <code>Z</code> (maiúsculo - <code>Shift + z</code>).<br><br>Abre a busca do Zoxide: digite o nome de qualquer pasta frequente e o Yazi salta direto para ela!	yazi::navegacao
Como <b>criar um novo arquivo</b> ou uma <b>nova pasta</b> no Yazi?	Aperte a letra <code>a</code> e digite o nome:<br>• Para criar um <b>arquivo</b>: digite o nome normalmente (ex: <code>script.py</code>).<br>• Para criar uma <b>pasta</b>: termine o nome com barra <code>/</code> (ex: <code>minha_pasta/</code>).	yazi::operacoes
Como <b>apagar arquivos ou pastas</b> no Yazi?	• <code>d</code> (minúsculo): Envia o item para a <b>Lixeira</b> com segurança.<br>• <code>D</code> (maiúsculo - <code>Shift + d</code>): <b>Deleta permanentemente</b> sem passar pela lixeira.	yazi::operacoes
Como <b>copiar, recortar e colar</b> arquivos no Yazi?	Selecione o arquivo e use:<br>• <code>y</code>: <b>Copiar</b> (Yank)<br>• <code>x</code>: <b>Recortar</b> (Cut)<br>• <code>p</code>: <b>Colar</b> na pasta onde você estiver (Paste)	yazi::operacoes
Como <b>renomear um arquivo</b> individualmente ou fazer <b>Renomeação em Massa (Bulk Rename)</b> no Yazi?	• <code>r</code>: Renomear o arquivo atual.<br>• <code>R</code> (maiúsculo): Abre todos os arquivos selecionados no <b>Neovim</b> para você editar dezenas de nomes de uma vez via busca e substituição!	yazi::operacoes
Como <b>selecionar múltiplos arquivos</b> no Yazi para copiar, mover ou apagar em lote?	• <code>Barra de Espaço</code>: Seleciona o arquivo atual e pula automaticamente para o próximo.<br>• <code>v</code>: Ativa a <b>Seleção Visual contínua</b> (mova com j/k para marcar dezenas de arquivos).	yazi::selecao
Como abrir e gerenciar <b>Abas Internas</b> dentro do Yazi?	• <code>t</code>: Abre uma <b>Nova Aba</b> interna.<br>• <code>w</code>: <b>Fecha</b> a aba atual.<br>• <code>1</code> a <code>9</code>: Alterna diretamente entre as abas 1 a 9.<br>• <code>[</code> / <code>]</code>: Aba anterior / próxima aba.	yazi::abas
Como alterar as informações exibidas ao lado de cada arquivo (<b>Linemode: Tamanho, Modificação, Permissões</b>)?	Aperte <code>m</code> seguido de:<br>• <code>m</code> + <code>s</code>: Mostra o <b>Tamanho (Size)</b> do arquivo.<br>• <code>m</code> + <code>m</code>: Mostra a <b>Data de Modificação</b>.<br>• <code>m</code> + <code>p</code>: Mostra as <b>Permissões Unix</b> (rwxr-xr-x).<br>• <code>m</code> + <code>n</code>: Oculta detalhes extras (Clean).	yazi::visualizacao
Como <b>mostrar ou ocultar arquivos e pastas ocultas (dotfiles)</b> no Yazi?	Aperte a tecla <code>.</code> (ponto).<br><br>Alterna instantaneamente a visibilidade de arquivos como <code>.git</code>, <code>.config</code>, etc.	yazi::navegacao
Como <b>compactar arquivos para .ZIP</b> com 1 segundo no Yazi?	Selecione os arquivos e aperte:<br><code>c</code> + <code>z</code><br><br>Gera um arquivo <code>.zip</code> compatível com qualquer sistema.	yazi::compactacao
Como compactar arquivos em <b>Ultra-Compressão (.7Z)</b> ou formato padrão Linux (<b>.TAR.GZ</b>)?	• <code>c</code> + <code>7</code>: Compacta em <b>.7Z</b> (máxima taxa de compressão LZMA2).<br>• <code>c</code> + <code>t</code>: Compacta em <b>.TAR.GZ</b> (padrão Linux/servidores).<br>• <code>c</code> + <code>c</code>: Abre prompt para escolher nome e formato personalizado.	yazi::compactacao
Como <b>descompactar/extrair um arquivo</b> com apenas 1 tecla no Yazi?	Coloque o cursor sobre o arquivo compactado (.zip, .rar, .7z, .tar.gz):<br>• <code>X</code> (maiúsculo - <code>Shift + x</code>): <b>Extrai para uma subpasta limpa</b> com o mesmo nome do arquivo.<br>• <code>Enter</code>: Em arquivos compactados, extrai automaticamente!<br>• <code>e</code> + <code>x</code>: Extrai solto na pasta atual (Extract here).	yazi::compactacao
No Yazi, o que são os atalhos <b>GOTO (tecla g)</b> para saltos rápidos no disco <code>/mnt/dados</code>?	Aperte <code>g</code> seguido de uma letra de destino:<br>• <code>g</code> + <code>i</code>: <code>00_Inbox</code> (Downloads)<br>• <code>g</code> + <code>v</code>: <code>04_Dev</code> (Projetos & Git)<br>• <code>g</code> + <code>p</code>: <code>01_Pessoal</code> (Documentos)<br>• <code>g</code> + <code>e</code>: <code>03_Estudos_Carreira</code><br>• <code>g</code> + <code>j</code>: <code>06.4_Games</code> (Jogos)<br>• <code>g</code> + <code>m</code>: <code>05_Midias</code> (Vídeos/Fotos)<br>• <code>g</code> + <code>D</code>: Raiz do <code>/mnt/dados</code><br>• <code>g</code> + <code>.</code>: Pasta <code>~/dotfiles</code><br>• <code>g</code> + <code>h</code>: Pasta Home (<code>~</code>)	yazi::saltos_goto
No Yazi, o que são as <b>Ações Master (Shift + M)</b> integradas ao ecossistema?	Aperte <code>M</code> (Shift + m) seguido de:<br>• <code>M</code> + <code>o</code>: Roda o <b>Organizador Inteligente</b> de downloads (`organizar --all`).<br>• <code>M</code> + <code>d</code>: Roda o diagnóstico de integridade (`organizar --doctor`).<br>• <code>M</code> + <code>s</code>: Faz backup de saves de jogos com Ludusavi.<br>• <code>M</code> + <code>g</code>: Abre a interface do <b>LazyGit</b> na pasta atual.<br>• <code>M</code> + <code>t</code>: Abre um novo <b>Terminal</b> apontado para a pasta atual.	yazi::acoes_master
Como <b>copiar o caminho completo</b> ou o <b>nome do arquivo</b> para a Área de Transferência no Yazi?	• <code>c</code> + <code>p</code>: Copia o <b>Caminho Completo</b> (ex: <code>/mnt/dados/04_Dev/meu_projeto/main.py</code>).<br>• <code>c</code> + <code>f</code>: Copia apenas o <b>Nome do Arquivo</b> (ex: <code>main.py</code>).<br>• <code>c</code> + <code>d</code>: Copia o caminho da <b>Pasta Pai</b> (ex: <code>/mnt/dados/04_Dev/meu_projeto</code>).	yazi::metadados
O que fazer se você esquecer qualquer atalho do Yazi durante a navegação?	Aperte a tecla <code>~</code> (til).<br><br>Abre o menu de ajuda interativo na tela com todas as categorias e teclas disponíveis!	yazi::fundamentos
Como <b>sair</b> do Yazi e manter o seu terminal na pasta que você estava navegando?	Aperte a letra <code>q</code>.<br><br>O Yazi se fecha e o seu shell já estará no diretório onde você navegou!	yazi::fundamentos
Como desmarcar apenas UM arquivo ou pasta que você selecionou por engano sem perder as outras seleções no Yazi?	Coloque o cursor sobre o item errado e aperte a <b>Barra de Espaço</b>.<br><br>A Barra de Espaço funciona como um <b>Toggle individual</b>: se o item já estiver selecionado, ela remove a seleção apenas dele, mantendo todas as outras dezenas de seleções 100% intactas!	yazi::selecao
Como desmarcar um bloco contínuo de arquivos selecionados por engano no Yazi?	Aperte <code>V</code> (maiúsculo - <code>Shift + v</code>) para entrar no <b>Modo Visual Unset</b>.<br><br>Agora mova com <code>j</code> ou <code>k</code> sobre o trecho que deseja desmarcar: ele remove a seleção por onde passar e mantém todo o restante selecionado!<br><br>• Aperte <code>&lt;Esc&gt;</code> para sair do modo visual.	yazi::selecao
Como desmarcar todos os arquivos, selecionar tudo ou inverter seleção no Yazi?	• <code>u</code>: <b>Desmarca tudo</b> (limpa todas as seleções ativas de uma vez).<br>• <code>Ctrl + a</code>: <b>Seleciona todos</b> os arquivos da pasta atual.<br>• <code>Ctrl + r</code>: <b>Inverte a seleção</b> (o que estava marcado fica desmarcado e vice-versa).	yazi::selecao
Como pular direto para o primeiro arquivo, para o último ou rolar meia tela no Yazi?	Usa a mesma memória muscular do Vim:<br>• <code>g g</code>: Pula para o <b>primeiro arquivo</b> (topo da pasta).<br>• <code>G</code> (Shift + g): Pula para o <b>último arquivo</b> (rodapé da pasta).<br>• <code>Ctrl + d</code>: Rola meia página para baixo (Down).<br>• <code>Ctrl + u</code>: Rola meia página para cima (Up).	yazi::navegacao
Como fazer uma busca profunda por nome de arquivo em todas as subpastas dentro do Yazi?	Aperte <code>s</code> (ou <code>/</code>).<br><br>Abre a busca integrada do <b>fd / fzf</b>: digite qualquer trecho do nome e o Yazi encontra o arquivo em qualquer nível de subpastas instantaneamente!	yazi::navegacao
Como alterar a ordenação de arquivos (por tamanho, data de modificação ou tipo) no Yazi?	Aperte a tecla <code>,</code> (vírgula):<br>• <code>,</code> + <code>m</code>: Ordenar por <b>Data de Modificação</b>.<br>• <code>,</code> + <code>s</code>: Ordenar por <b>Tamanho (Size)</b>.<br>• <code>,</code> + <code>a</code>: Ordenar por <b>Nome Alfabético</b>.<br>• <code>,</code> + <code>e</code>: Ordenar por <b>Extensão</b>.<br>• <code>,</code> + <code>r</code>: Inverter a ordem (Reverse).	yazi::visualizacao
Como montar ou desconectar o Google Drive de 5TB diretamente por dentro do Yazi?	Aperte <code>M</code> (Shift + m) seguido de <code>G</code> (Shift + g):<br><code>M</code> + <code>G</code><br><br>Monta o Google Drive virtual de 5TB em segundo plano via Rclone VFS com notificação instantânea na tela!	yazi::acoes_master

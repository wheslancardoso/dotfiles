#deck:Cockpit Dev::05 - Terminal & Modern CLI
O que é o <b>Zoxide (comando <code>z</code>)</b> e por que você nunca mais deve digitar caminhos longos com <code>cd</code>?	O <b>Zoxide</b> é um substituto inteligente do <code>cd</code> que aprende as pastas que você mais usa.<br><br>Em vez de digitar <code>cd /mnt/dados/04_Dev/meu_projeto_gigante</code>, você só digita:<br><code>z projeto</code><br><br>Ele salta instantaneamente para a pasta de qualquer lugar do sistema!	terminal::modern_cli
Como <b>pesquisar comandos antigos no histórico do terminal</b> usando o <b>FZF</b> em 1 segundo?	No terminal, aperte <code>Ctrl + r</code>.<br><br>Abre um menu de busca interativo instantâneo. Digite qualquer pedaço de um comando que você rodou no passado, use as setas para selecionar e aperte <code>Enter</code> para executar!	terminal::modern_cli
No terminal, para que serve o atalho <b><code>Ctrl + t</code></b> e o atalho <b><code>Alt + c</code></b> do FZF?	• <code>Ctrl + t</code>: Abre busca difusa de arquivos e <b>cola o caminho do arquivo selecionado direto no seu comando atual</b>.<br>• <code>Alt + c</code>: Abre busca de diretórios e já faz <code>cd</code> diretamente para a pasta selecionada.	terminal::modern_cli
Como <b>apagar toda a linha de comando</b> ou <b>apagar a palavra anterior</b> sem segurar a tecla Backspace?	• <code>Ctrl + u</code>: <b>Apaga a linha inteira</b> da posição do cursor até o início.<br>• <code>Ctrl + w</code>: <b>Apaga a palavra anterior</b> imediatamente para trás.<br>• <code>Ctrl + k</code>: Apaga do cursor até o final da linha.	terminal::readline
Como ir direto para o <b>início</b> ou para o <b>final</b> da linha no terminal?	• <code>Ctrl + a</code>: Pula o cursor para o <b>início absoluto</b> da linha de comando.<br>• <code>Ctrl + e</code>: Pula o cursor para o <b>final</b> da linha.<br><br><i>(Substitui as teclas Home e End sem tirar a mão da posição de digitação!)</i>	terminal::readline
Como <b>reaproveitar o último argumento</b> do comando anterior com 1 toque de tecla?	Aperte <code>Alt + .</code> (Alt + ponto).<br><br><i>Exemplo: Você criou uma pasta com <code>mkdir projeto_incrivel</code>. No comando seguinte, digite <code>cd </code> e aperte <code>Alt + .</code> para colar <code>projeto_incrivel</code> na hora!</i>	terminal::readline
O que você digita quando roda um comando longo e o sistema avisa <b>"Permission denied"</b> por esquecer o <code>sudo</code>?	Basta digitar:<br><code>sudo !!</code><br><br>Os dois pontos de exclamação <code>!!</code> representam o comando anterior inteiro, executando-o imediatamente com permissões de administrador.	terminal::readline
Como <b>limpar a tela do terminal</b> instantaneamente sem apagar o que você está digitando?	Aperte <code>Ctrl + l</code>.<br><br>Diferente do comando <code>clear</code>, o <code>Ctrl + l</code> limpa a poluição visual mantendo intacto o comando que você estava no meio de escrever.	terminal::readline
O que é o <b>Eza</b> e quais são os aliases padrão de listagem no seu shell?	É o substituto moderno do <code>ls</code>, com ícones coloridos, permissões legíveis e status do Git:<br>• <code>ls</code>: Listagem limpa com ícones.<br>• <code>ll</code>: Lista detalhada com tamanho legível (KB/MB), datas e donos.<br>• <code>la</code>: Lista detalhada incluindo arquivos ocultos (dotfiles).<br>• <code>lt</code>: Exibe a pasta em formato de <b>Árvore hierárquica (Tree)</b>.	terminal::modern_cli
O que é o <b>Bat</b> e por que ele substitui o comando clássico <code>cat</code>?	O <b>Bat</b> é o visualizador de texto com <b>coloração de sintaxe automática para mais de 100 linguagens</b>, números de linha e integração com Git (mostra barras coloridas para linhas adicionadas/modificadas).<br><br><i>Basta digitar <code>cat arquivo.py</code> (já apelidado para o Bat no seu sistema).</i>	terminal::modern_cli
Qual é a diferença entre o <b>Grep clássico</b> e o <b>Ripgrep (<code>rg</code>)</b> no seu terminal?	O <b>Ripgrep (<code>rg</code>)</b> é escrito em Rust e é até <b>10x mais rápido que o grep</b> tradicional, além de respeitar automaticamente o seu arquivo <code>.gitignore</code> (não pesquisa dentro de pastas inúteis como <code>node_modules</code> ou <code>.git</code>).<br><br><i>Uso: <code>rg "minha_funcao"</code></i>	terminal::modern_cli
Qual ferramenta moderna substitui o antigo comando <code>find</code> do Linux?	O <b><code>fd</code></b>.<br><br>Muito mais rápido, intuitivo e com cores.<br>• Em vez de <code>find . -name "*teste*"</code>, você simplesmente digita:<br><code>fd teste</code>	terminal::modern_cli
No seu sistema, qual comando do terminal <b>atualiza todos os pacotes do Arch, AUR e Flatpaks</b> de uma só vez?	Basta digitar <code>update</code>.<br><br>Ele executa a sincronização segura dos repositórios oficiais, AUR via yay/paru e pacotes Flatpak em sequência.	terminal::dotfiles_aliases
No seu sistema, qual comando <b>limpa o cache de pacotes antigos e dependências órfãs</b> para liberar espaço em disco?	Basta digitar <code>clean</code>.<br><br>Remove pacotes obsoletos do cache do Pacman mantendo apenas versões seguras para rollback e elimina lixo do sistema.	terminal::dotfiles_aliases
O que faz o comando <b><code>organizar</code></b> criado no seu sistema?	Executa o <b>Organizador Inteligente de Arquivos</b> do seu setup:<br>• Lê arquivos soltos na pasta de Downloads / Inbox e os categoriza automaticamente (PDFs, instaladores, planilhas, imagens, etc.) nas pastas canônicas da partição <code>/mnt/dados</code>.<br>• Use <code>organizar --all</code> para processar ou <code>organizar --doctor</code> para diagnóstico.	terminal::dotfiles_aliases
Qual comando do terminal exibe o <b>resumo visual completo do hardware, kernel, memória e distro</b> com a logo do sistema?	Digite <code>fastfetch</code>.<br><br>Mostra uptime, CPU, GPU, resolução de tela, versão do Hyprland e consumo de RAM em milissegundos.	terminal::modern_cli

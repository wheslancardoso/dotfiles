#deck:Cockpit Dev::04 - Zellij Multiplexer
O que é o <b>Zellij</b> e por que ele é superior a usar múltiplas abas soltas de terminal?	É um <b>multiplexador de terminal moderno</b> escrito em Rust (substituto amigável do Tmux).<br><br>Ele permite dividir a tela em múltiplos painéis, criar abas e, o mais importante: <b>suas sessões nunca morrem</b> mesmo se você fechar o terminal ou reiniciar a interface gráfica.	zellij::fundamentos
Como <b>iniciar uma nova sessão nomeada</b> ou <b>listar as sessões ativas</b> no Zellij via terminal?	• Criar sessão nomeada: <code>zellij -s nome_do_projeto</code><br>• Listar todas as sessões rodando: <code>zellij ls</code><br>• Reconectar a uma sessão existente: <code>zellij attach nome_do_projeto</code>	zellij::sessoes
O que é o <b>Layout Vibe Coding (`vibe`)</b> configurado no seu ecossistema?	É uma sessão pré-moldada do Zellij dividindo a tela perfeitamente:<br>• <b>Esquerda (70%)</b>: LazyVim para edição rápida.<br>• <b>Direita Superior (30%)</b>: Agente autônomo Antigravity CLI (<code>agy</code>).<br>• <b>Direita Inferior (30%)</b>: Terminal para rodar servidores, testes e builds.<br><br><i>Para iniciar: basta digitar <code>vibe</code> no terminal!</i>	zellij::fundamentos
Como <b>mover o foco entre os painéis divididos</b> do Zellij sem precisar de tecla prefixo?	Segure <code>Alt</code> e use as teclas Vim:<br>• <code>Alt + h</code>: Foco no painel da <b>Esquerda</b><br>• <code>Alt + l</code>: Foco no painel da <b>Direita</b><br>• <code>Alt + j</code>: Foco no painel de <b>Baixo</b><br>• <code>Alt + k</code>: Foco no painel de <b>Cima</b>	zellij::navegacao
Como <b>alternar entre layouts de divisão de tela</b> pré-configurados no Zellij?	• <code>Alt + [</code>: Volta para o layout anterior.<br>• <code>Alt + ]</code>: Avança para o próximo layout.<br><br><i>(Alterna instantaneamente entre layouts verticais, horizontais e compactos!)</i>	zellij::layouts
Como <b>redimensionar painéis</b> rapidamente no Zellij?	• <code>Alt + =</code> (ou <code>Alt + +</code>): <b>Aumenta</b> o tamanho do painel ativo.<br>• <code>Alt + -</code>: <b>Diminui</b> o tamanho do painel ativo.	zellij::panes
Como criar uma <b>nova divisão de tela (Pane)</b> no Zellij?	Aperte <code>Ctrl + p</code> (Modo Pane) seguido de:<br>• <code>d</code>: Cria um novo painel <b>abaixo</b> (Down).<br>• <code>r</code>: Cria um novo painel na <b>direita</b> (Right).<br>• <code>n</code>: Cria um novo painel automático.<br>• <code>x</code>: <b>Fecha</b> o painel atual.	zellij::panes
Como colocar um painel do Zellij em <b>Tela Cheia temporária</b> ou transformá-lo em <b>Janela Flutuante</b>?	Aperte <code>Ctrl + p</code> seguido de:<br>• <code>f</code>: Alterna <b>Tela Cheia (Fullscreen)</b> no painel atual.<br>• <code>w</code>: Transforma o painel em uma <b>janela flutuante</b> centralizada.<br>• <code>z</code>: Alterna a exibição das bordas dos painéis (Toggle Frames).	zellij::panes
Como <b>trocar de posição / arrastar painéis</b> no Zellij (Move Mode)?	Aperte <code>Ctrl + h</code> (Modo Move) e use as teclas <code>h / j / k / l</code> para arrastar o painel ativo de lugar na grade de tela!	zellij::panes
Como gerenciar <b>Abas internas (Tabs)</b> no Zellij?	Aperte <code>Ctrl + t</code> (Modo Tab) seguido de:<br>• <code>n</code>: Cria uma <b>Nova Aba</b>.<br>• <code>x</code>: <b>Fecha</b> a aba atual.<br>• <code>r</code>: <b>Renomeia</b> a aba (digite o nome e aperte Enter).<br>• <code>h / l</code>: Navega entre a aba anterior e a próxima.	zellij::tabs
O que é o recurso de <b>Sincronizar Abas (Sync Tabs)</b> no Zellij?	Aperte <code>Ctrl + t</code> seguido de <code>s</code>.<br><br>Permite que <b>tudo o que você digitar seja replicado em todos os painéis ao mesmo tempo</b> (perfeito para atualizar múltiplos servidores ou rodar comandos em lote).	zellij::tabs
Como <b>desconectar (Detach)</b> de uma sessão do Zellij sem encerrar os programas que estão rodando nela?	Aperte <code>Ctrl + o</code> (Modo Session) seguido de <code>d</code> (de <i>Detach</i>).<br><br>Você volta para o shell normal, e tudo o que estava rodando no Zellij continua em segundo plano.<br><br><i>Para voltar depois: basta digitar <code>zellij attach</code>!</i>	zellij::sessoes
Como abrir o <b>Gerenciador Visual de Sessões</b> dentro do Zellij?	Aperte <code>Ctrl + o</code> seguido de <code>w</code>.<br><br>Abre um menu com todas as sessões ativas para você alternar ou encerrar sem ir para o terminal.	zellij::sessoes
Como navegar pelo <b>histórico de rolagem (Scrollback) e pesquisar texto</b> no Zellij?	Aperte <code>Ctrl + s</code> (Modo Scroll) seguido de:<br>• <code>s</code>: Inicia a <b>busca por palavra</b>.<br>• <code>j / k</code>: Rola linha por linha para baixo/cima.<br>• <code>u / d</code>: Rola meia página para cima/baixo.<br>• Aperte <code>&lt;Esc&gt;</code> para sair do modo scroll.	zellij::scroll
O que fazer se um comando ou programa de terminal usar teclas que conflitam com o Zellij?	Aperte <code>Ctrl + g</code> (Modo <b>LOCKED</b>).<br><br>Isso <b>trava todos os atalhos do Zellij</b>, permitindo que você envie qualquer combinação de teclas diretamente para o app.<br><br><i>Para destravar o Zellij: aperte <code>Ctrl + g</code> novamente.</i>	zellij::fundamentos
Como <b>encerrar definitivamente</b> todas as janelas e fechar a sessão do Zellij?	Aperte <code>Ctrl + q</code>.	zellij::sessoes

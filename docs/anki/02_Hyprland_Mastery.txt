No <b>Hyprland</b>, qual é a <b>tecla mestre (Super/Mod)</b> no teclado físico?	É a <b>tecla Windows</b> (ou <i>Command</i> no Mac).<br><br>Nos arquivos de configuração ela aparece como <code>$mainMod</code>.	hyprland::fundamentos
Qual atalho abre um <b>novo terminal</b> instantaneamente no Hyprland?	<code>Super + Enter</code> (ou <code>Super + Return</code>).<br><br>Abre o terminal padrão ultra-rápido (Ghostty ou Kitty).	hyprland::janelas
Qual atalho <b>fecha/mata a janela ativa</b> no Hyprland?	<code>Super + Q</code> (de <i>Quit</i>).	hyprland::janelas
O que fazer se um <b>programa travar ou congelar</b> a tela e o <code>Super + Q</code> não responder?	Aperte <code>Super + Backspace</code>.<br><br>O cursor vira uma <b>mira de precisão</b>: basta clicar na janela travada para forçar o encerramento imediato do processo.	hyprland::janelas
Qual atalho alterna entre os layouts de <b>Teclado US Internacional</b> (acentos e ç) e <b>ABNT2</b>?	<code>Super + Espaço</code>.<br><br>Uma notificação no topo direito confirma o layout ativo (us-intl ↔ br).	hyprland::sistema
Como transformar qualquer janela em <b>Flutuante (Floating)</b> ou voltar para <b>Ladrilhada (Tiling)</b>?	<code>Super + Shift + Espaço</code>.<br><br>Permite redimensionar e mover janelas livremente como no Windows/macOS.	hyprland::janelas
Como colocar uma janela em <b>Tela Cheia (Fullscreen)</b> no Hyprland?	• <code>Super + F</code>: Tela cheia total (Fullscreen 0 - esconde Waybar e bordas).<br>• <code>Super + Shift + F</code>: Maximizar mantendo a barra visível (Maximize).	hyprland::janelas
Como <b>mover o foco entre as janelas abertas</b> sem tirar as mãos do teclado?	Segure <code>Super</code> e use as teclas estilo Vim:<br>• <code>Super + H</code>: Foca a janela da <b>Esquerda</b><br>• <code>Super + L</code>: Foca a janela da <b>Direita</b><br>• <code>Super + J</code>: Foca a janela de <b>Baixo</b><br>• <code>Super + K</code>: Foca a janela de <b>Cima</b>	hyprland::janelas
Como <b>trocar a posição de uma janela</b> com outra na tela (arrastar via teclado)?	Segure <code>Super + Shift</code> e use:<br>• <code>Super + Shift + H / J / K / L</code><br><br>A janela se move na grade do layout tiling instantaneamente.	hyprland::janelas
Como alternar rapidamente entre as últimas janelas abertas (estilo Windows <b>Alt + Tab</b>)?	• <code>Alt + Tab</code>: Alternância instantânea com 0ms de lag.<br>• <code>Super + Tab</code>: Seletor visual interativo via Rofi com busca de janelas e ícones.	hyprland::janelas
Como abrir o <b>Menu de Aplicativos (Launcher)</b> no Hyprland?	<code>Super + D</code> (ou apenas clique na tecla <code>Super</code>).<br><br>Abre o lançador Rofi para digitar o nome de qualquer app.	hyprland::sistema
Como abrir e fechar o <b>Dropdown Scratchpad do Spotify</b> no Hyprland?	<code>Super + M</code>.<br><br>O Spotify desce do topo com fundo translúcido Catppuccin. Aperte <code>Super + M</code> de novo para ocultar sem fechar a música.	hyprland::scratchpad
Como abrir e fechar o <b>Terminal Scratchpad suspenso (Quake-style)</b>?	<code>Super + '</code> (tecla grave / apóstrofo) ou <code>Super + U</code>.<br><br>Abre um terminal suspenso rápido para rodar um comando rápido e sumir sem poluir seus workspaces.	hyprland::scratchpad
Como abrir a ferramenta de <b>Busca Instantânea de Arquivos (FSearch)</b> no Hyprland?	<code>Super + Shift + F</code>.<br><br>O equivalente ao <i>Everything</i> do Windows: indexa e encontra qualquer arquivo do disco em 2 milissegundos.	hyprland::ferramentas
Como abrir o histórico completo da <b>Área de Transferência (Clipboard)</b> com suporte a imagens?	<code>Alt + V</code> (abre o <b>CopyQ</b> com abas e busca persistente).<br><br><i>(Ou <code>Super + V</code> para o histórico rápido via Cliphist).</i>	hyprland::ferramentas
Como tirar uma <b>Captura de Tela (Print) com anotações, setas e blur</b>?	<code>Super + Shift + S</code>.<br><br>Abre o <b>Flameshot</b> com todas as ferramentas de desenho e cópia para o clipboard.<br><br><i>(Aperte a tecla <code>Print</code> pura para captura rápida de tela cheia).</i>	hyprland::ferramentas
Como abrir a <b>colinha rápida de todos os atalhos (KeyHints)</b> na tela?	<code>Super + H</code>.<br><br>Abre um painel translúcido central com a lista completa de atalhos do sistema.	hyprland::sistema
Como <b>bloquear a tela</b> e como abrir o <b>Menu de Desligar/Reiniciar</b>?	• Bloquear tela: <code>Super + L</code> (ou <code>Super + Alt + L</code>)<br>• Menu de saída (Wlogout): <code>Ctrl + Alt + P</code> ou <code>Super + X</code>	hyprland::sistema
Como abrir o <b>Gerenciador de Tarefas do Sistema (Btop)</b> em popup flutuante?	<code>Ctrl + Shift + Esc</code> (ou <code>Super + Esc</code>).<br><br>Abre o monitor de hardware em tempo real com uso de CPU, GPU, RAM e processos.	hyprland::ferramentas
Como ativar o <b>Filtro Noturno de Luz Azul (Night Light)</b> para descanso ocular?	<code>Super + N</code>.<br><br>Alterna o modo noturno âmbar (hyprsunset).	hyprland::sistema
No Hyprland, o que acontece quando você <b>agita o mouse rapidamente</b>?	O cursor <b>aumenta de tamanho</b> temporariamente na tela (efeito <i>Shake to Find</i> do KDE/macOS).<br><br>Facilita encontrar o cursor instantaneamente em múltiplos monitores.	hyprland::sistema
Como abrir o <b>Menu de Presets de Áudio e Graves (EasyEffects)</b>?	<code>Super + Alt + A</code>.<br><br>Abre o menu Rofi para escolher entre: Hip-Hop Bass, Sub-Bass 808, Dolby Atmos, Podcast Vocal ou Som Neutro.	hyprland::audio

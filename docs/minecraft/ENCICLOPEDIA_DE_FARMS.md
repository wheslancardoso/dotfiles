# 🌾 ENCICLOPÉDIA DEFINITIVA DE TODAS AS FARMS DO MINECRAFT (CATÁLOGO 100% EXAUSTIVO)
> **Filosofia:** Nada no seu mundo deve ser feito à mão. Cada gota de mel, cada slimeball, cada tridente e cada flor deve vir de uma máquina automatizada.

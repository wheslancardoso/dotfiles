# 📂 Yazi Quick Cheat Sheet

## 🚀 Navegação Básica
- `j` / `k`      : Mover para baixo / cima
- `h` / `l`      : Voltar pasta / Entrar na pasta
- `Enter`        : Abrir arquivo (app padrão)
- `q`            : Sair do Yazi

## ✏️ Gestão de Arquivos
- `r`            : Renomear
- `R`            : **Bulk Rename** (Editar lista no Neovim)
- `a` + `i`      : Criar novo Arquivo (Insert)
- `a` + `d`      : Criar novo Diretório
- `d` + `d`      : Mover para a Lixeira (Trash)
- `D`            : Deletar permanentemente
- `f`            : Filtrar arquivos (Busca rápida)

## 📦 Compressão & Extração (ouch)
- `a` + `e`      : **Extrair** (detecta formato auto)
- `a` + `c`      : **Compactar** para .zip

## 🛠️ Utilitários
- `H`            : Ver este Guia (Shift + H)
- `y`            : Copiar Caminho (Copy Path)
- `T`            : Abrir Terminal nesta pasta
- `.`            : Mostrar/Ocultar arquivos ocultos
- `v`            : Seleção visual (como no Vim)
- `Space`        : Selecionar arquivo individual

---
*Dica: O Bulk Rename (R) é seu melhor amigo para organizar pastas inteiras!*
